name: balance-check
description: Runs seeded simulations of the game and reports resource curves, and confirms that only an incident's correct order resolves it at the causal layer. Use after changing simulation rules or incidents.
---

Play each affected incident once per order under fixed seeds, then report the resource curves and which orders resolved the incident at the causal layer. Any wrong order that resolves it is a failure.

The seeded simulation runner has not been built yet. If the project commands in `CLAUDE.md` do not list one, say so and stop rather than estimating results.
